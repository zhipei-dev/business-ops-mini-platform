# Support

This repository is a public portfolio project and does not include a paid support contract or SLA.

## Questions and defects

Use GitHub Issues for:

- reproducible workflow/state-transition defects
- inventory or audit behavior problems
- setup/configuration/handoff documentation gaps
- narrowly scoped enhancement requests

Include the Java version, operating system, command, synthetic data scenario, expected behavior, and observed behavior when relevant.

## Security and data

Do not post credentials, private supplier/customer data, production database contents, or secrets in public issues. Use synthetic reproduction data only.

Review `docs/SECURITY_AND_LIMITATIONS.md` before reporting behavior that may be an intentional product boundary.

## Scope

Support covers the documented local portfolio workflow. Production ERP hosting, identity, tenancy, accounting/compliance, external supplier/customer integrations, backups, and operational SLAs are outside scope.
